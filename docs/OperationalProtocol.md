# Operational Protocol

- Qoovex tratta soltanto il cervello operativo pre-servizio e il Service Mode consultivo.
- Auth resta confinata in `apps/workspace`.
- Query DB solo in moduli server autorizzati.
- Sirio documenta candidati; non esporta componenti runtime.
- Logo solo da `@qoovex/brand`; icone applicative solo Phosphor.
- Phone, tablet e desktop mantengono dati e significati equivalenti.
- Nessun reset di dominio può cancellare dati auth.
