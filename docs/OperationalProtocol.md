# Operational Protocol

- Qoovex tratta soltanto il cervello operativo pre-service e il Service Mode consultivo.
- Auth resta confinata in `apps/workspace`.
- Query DB solo in moduli server autorizzati.
- Nessun design system, catalogo componenti o stile visuale e canonico dopo il reset.
- Nessun reset di dominio puo cancellare dati auth.
