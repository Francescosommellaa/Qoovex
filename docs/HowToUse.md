# How to use

1. Richiamare `get_task_context` dal server MCP `qoovex_brain`.
2. Per task UI chiamare `check_ui_task`; non esiste uno stile canonico da riusare dopo il reset.
3. Verificare README locale, codice reale e confini auth.
4. Non inventare backend Event, pricing o permessi non ancora approvati.
5. Eseguire lint, type-check, test e build pertinenti.
6. Aggiornare il Brain e appendere il riepilogo a `00_System/session-log.md`.
