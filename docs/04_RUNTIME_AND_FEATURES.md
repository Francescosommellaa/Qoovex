# Runtime and active features

Workspace espone auth credentials e OAuth opzionale, MFA, inviti e supporto auditato, dashboard e console Qoovex Admin. Il dominio attivo include document types e requirements configurabili, documenti/versioni, worker, cantieri, scadenze, checklist, evidence, pacchetti e share link.

Sono attive notifiche interne, preferenze e digest email, reminder, assegnazioni granulari, audit log prodotto, inventario dati, export metadata, retention, job di cancellazione e verifica/bonifica Blob orfani. Le API dominio e le viste workspace usano il modello `Organization*` reale.

La base tecnica e testata contro isolamento tenant, accesso granulare e assenza di regressioni del vecchio modello tenant.
