# Sirio Source

Scopo: sorgente dell'app Sirio.

Metti qui:
- entrypoint Next, layout, pagina principale, sezioni e support files solo di Sirio.

Non mettere qui:
- componenti condivisi cross-app;
- asset statici.

Regole:
- `app/` contiene routing e shell Next;
- `sections/` contiene demo modulari e leggibili;
- ogni nuova cartella sorgente qui dentro deve avere il suo `README.md`.
