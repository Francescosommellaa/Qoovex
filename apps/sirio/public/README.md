# Sirio Public

Scopo: asset statici usati solo dall'app Sirio.

Metti qui:
- file statici referenziati da `apps/sirio`;
- asset utili alla documentazione visuale del design system.

Non mettere qui:
- asset condivisi con altre app: vanno in `packages/brand`;
- file generati, export temporanei o versioni duplicate dello stesso asset.

Regole:
- naming esplicito in `kebab-case`;
- mantieni una sola versione canonica per asset.
