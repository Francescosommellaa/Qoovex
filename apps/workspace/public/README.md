# Workspace Public

Scopo: asset statici usati solo da Qoovex workspace.

Metti qui:
- asset esclusivi dell'app workspace.

Non mettere qui:
- asset brand condivisi;
- file generati o copie di asset globali.

Regole:
- se l'asset serve anche a `apps/web` o `apps/sirio`, spostalo in `packages/brand`;
- conserva solo file realmente referenziati dall'app.
