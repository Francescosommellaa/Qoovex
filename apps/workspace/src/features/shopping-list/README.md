# Shopping List Feature

Scopo: casi d'uso legati alla lista della spesa.

Metti qui:
- generazione lista, check/uncheck, ordinamento e mutazioni utente.

Non mettere qui:
- dominio puro di ingredienti;
- schermate complete.

Regole:
- separa la logica di calcolo dai componenti di pagina;
- tieni qui solo cio` che rappresenta un'interazione.
