# Explore Feature

Scopo: casi d'uso interattivi della sezione esplora.

Metti qui:
- ricerca, filtri, like, fork e interazioni specifiche di explore.

Non mettere qui:
- la view completa della pagina explore;
- primitive riusabili di `Recipe` o `Menu`.

Regole:
- usa `entities/menu` e `entities/recipe` per il dominio;
- lascia a `views/explore` la composizione schermata.
