# Recipe Editor Feature

Scopo: casi d'uso di creazione e modifica ricette.

Metti qui:
- form editor, submit flow, validazione e orchestrazione ingredienti/istruzioni.

Non mettere qui:
- primitive visuali base della ricetta;
- pagine complete o card widget.

Regole:
- `Recipe` come dominio sta in `entities/recipe`;
- l'editor resta qui finche' e` un caso d'uso utente.
