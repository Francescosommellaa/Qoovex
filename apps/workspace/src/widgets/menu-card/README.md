# Menu Card Widget

Scopo: card composita dedicata ai menu.

Metti qui:
- widget che presenta un menu con meta, azioni e stati combinati.

Non mettere qui:
- primitive base del dominio `Menu`;
- intera schermata menu.

Regole:
- usa `entities/menu` per parti di dominio;
- resta un blocco compositivo, non una view.
