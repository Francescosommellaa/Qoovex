# Navbar Widget

Scopo: navigazione composita dell'app workspace.

Metti qui:
- top navigation, responsive navigation e parti collegate alla shell.

Non mettere qui:
- design system base;
- logica di business di feature specifiche.

Regole:
- la navbar compone elementi shared/features, ma non contiene logica prodotto pesante;
- mantieni separati layout e casi d'uso.
