# Menu Entity

Scopo: codice che appartiene solo al dominio `Menu`.

Metti qui:
- model, mapper, badge, card part o helper dedicati al menu.

Non mettere qui:
- builder completi, flow di pubblicazione o composizioni pagina.

Regole:
- niente dipendenze da `features`, `widgets`, `views`;
- mantieni la cartella orientata al dominio, non al flusso utente.
