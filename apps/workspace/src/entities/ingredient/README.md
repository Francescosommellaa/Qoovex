# Ingredient Entity

Scopo: codice che appartiene solo al dominio `Ingredient`.

Metti qui:
- model, lib e ui legati all'ingrediente;
- formatter, parser o badge specifici dell'entita`.

Non mettere qui:
- editor ricetta, shopping list o flussi multi-entita`.

Regole:
- dipendenze consentite: `shared`, `packages` e codice locale della stessa entita`;
- se il codice descrive un'azione utente, non appartiene qui.
