# Work Plan Entity

Scopo: codice che appartiene solo al dominio `WorkPlan`.

Metti qui:
- tipi, mapper, ui atomiche e helper locali al piano di lavoro.

Non mettere qui:
- board interattive complete o orchestration tra task, membri e UI complessa.

Regole:
- se il codice e` un caso d'uso utente, appartiene a `features/work-plan-board`;
- mantieni chiaro il confine tra modello e flusso.
