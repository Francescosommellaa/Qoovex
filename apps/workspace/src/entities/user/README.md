# User Entity

Scopo: codice legato all'entita` `User`.

Metti qui:
- model, formatter e primitive visuali del profilo utente;
- helper di mapping tra dati auth e dati di dominio.

Non mettere qui:
- auth routing, onboarding o settings page complete.

Regole:
- separa il dominio `User` dalla gestione delle route di auth;
- niente dipendenze da layer superiori.
