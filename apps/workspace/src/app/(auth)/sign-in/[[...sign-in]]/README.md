# Sign-In Catch-All

Scopo: entrypoint Clerk richiesto dal framework per la route di login.

Metti qui:
- il solo `page.tsx` o file strettamente necessari al mount del componente Clerk.

Non mettere qui:
- business logic, fetch custom o componenti riusabili di prodotto.

Regole:
- il file deve restare sottile e dichiarativo;
- qualunque personalizzazione condivisa va estratta fuori da questo folder.
