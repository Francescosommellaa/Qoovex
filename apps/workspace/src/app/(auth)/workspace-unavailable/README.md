# Workspace Unavailable Route

Pagina pubblica di recupero per errori infrastrutturali del bootstrap workspace.

## Regole
- Usare quando il workspace non puo` essere caricato per DB/schema/env.
- Non usare per profilo utente incompleto: il profilo richiesto viene raccolto in `/sign-up`.
- Non mostrare dettagli tecnici o dati account all'utente.
