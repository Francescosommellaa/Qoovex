# `/checklists`

Pagina admin workspace per lista e creazione di checklist configurate dall'utente. Usa solo i service/API checklist gia protetti e non introduce template normativi.

`?view=open` seleziona lato server soltanto checklist con almeno una voce `OPEN` o `TO_REVIEW`; la pagina conserva scope cantiere e paginazione a 50 record con lookahead.
