# Document settings route

Tipi documento e requisiti documentali, fuori dalla lista operativa Documenti.

La pagina raggruppa i tipi per macroarea e categoria canonica, consente agli utenti con `settings:update` di creare tipi classificati e mostra due code per dati preesistenti: tipi `UNCLASSIFIED` e documenti senza tipo classificato. La classificazione e sempre esplicita. Gli ambiti `EVIDENCE` e `OTHER` restano in un flusso separato e non vengono convertiti automaticamente. La categoria riservata amministrativa e visibile come confine futuro ma non e attivabile.
