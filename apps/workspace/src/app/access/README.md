# Access Page

Pagina contestuale per assegnazioni di Collaboratori e lavoratori ai cantieri. L'associazione tra account Collaboratore e profilo Worker resta disponibile in disclosure avanzata per applicare lo scope personale, ma non assegna o modifica il ruolo organizzativo.

La gestione delle relazioni richiede permessi espliciti; l'`OWNER` configura accessi e assegnazioni, mentre un `COLLABORATOR` consulta o muta soltanto quanto consentito dai permessi persistiti. Le quattro letture iniziali restano parallele e le API restano la fonte di autorizzazione e tenant scope server-side. La route non e duplicata nella navigazione ordinaria o nei collegamenti rapidi.
