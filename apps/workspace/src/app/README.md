# Route Workspace attuale

Route prodotto presenti: home dell'unica Azienda su `/`, configurazione Azienda, attesa inviti Professionista, preferenze account, superfici Azienda dirette `/job-sites`, `/people` e `/payment-profile`, superfici cliente `/client`, export autenticati, auth, supporto, sicurezza, audit, data-control e console piattaforma. L'identificativo Azienda non fa parte delle route Workspace.

Il manifest capability e i test di contratto mantengono l'allowlist delle route prodotto. La loro presenza non equivale a flusso end-to-end verificato.
