# Route Workspace attuale

Route prodotto presenti: root di instradamento account, configurazione Azienda, attesa inviti Professionista, preferenze account, superfici Azienda `/org/[organizationId]`, superfici cliente `/client`, dettaglio cantiere, export autenticati, auth, supporto, sicurezza, audit, data-control e console piattaforma.

Il manifest capability e i test di contratto mantengono l'allowlist delle route prodotto. La loro presenza non equivale a flusso end-to-end verificato.
