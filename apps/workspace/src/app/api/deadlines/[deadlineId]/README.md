# Deadline Detail API

Gestisce una scadenza dell'azienda corrente.

- `PATCH /api/deadlines/[deadlineId]`: aggiorna metadati, data, promemoria, stato e relazioni.
- `DELETE /api/deadlines/[deadlineId]`: archivia soft e imposta `ARCHIVED`.

Questa API non valuta conformita e non stabilisce obblighi legali.
