# Shared Config

Scopo: costanti e config applicative della workspace app.

Metti qui:
- costanti, key, default config e mappe di configurazione interne all'app.

Non mettere qui:
- business rules globali gia` definite altrove;
- utility eseguibili o componenti UI.

Regole:
- nomi espliciti;
- niente configurazioni duplicate se esiste gia` una fonte canonica in `packages/config`.
