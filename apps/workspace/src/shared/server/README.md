# Servizi server foundation

I servizi applicano identità, tenant e permission server-derived. Sono presenti servizi attuali per account, Azienda, participant, inviti, agreement, timeline, step, richieste, proposte, pagamenti documentati, allegati, chiusura, export, processi e notifiche, oltre alle foundation auth, audit, supporto e data-control.

Gli allegati sono soltanto contestuali al cantiere. Sono presenti enqueue, processi registrati, ricerca e timeline attuale. Blob key e segreti non devono raggiungere output client. La presenza dei servizi non equivale a verifica end-to-end.
