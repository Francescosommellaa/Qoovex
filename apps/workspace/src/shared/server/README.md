# Servizi server foundation

I servizi applicano sempre identità, tenant e permission server-derived. Sono presenti servizi generici per Azienda/accessi, Worker/assegnazioni, JobSite minimo, file/versioni, prove, notifiche di sistema, audit, supporto e data-control.

Non esistono servizi prodotto legacy, enqueue automatici, reminder, processi registrati, ricerca o timeline. Blob key e segreti non raggiungono output client.
