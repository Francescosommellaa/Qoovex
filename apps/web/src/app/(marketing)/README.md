## Marketing Routes

Routing group marketing per il sito `apps/web`.

Contiene:
- pagine marketing (`home`, `pricing`, `product`, `enterprise`, `resources`, `contact`, `legal`)
- layout marketing condiviso

Regole:
- qui vive solo codice del sito vetrina, non logica prodotto
- riusare il design system (`@qoovex/ui`) e i token semantici
- sezioni condivise cross-page in `src/shared/sections`
