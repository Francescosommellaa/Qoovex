# Web App

Scopo: sito marketing Qoovex.

Metti qui:
- landing page, pricing, contenuti brand, SEO, conversione e navigazione marketing;
- componenti e sezioni specifiche del sito vetrina.

Non mettere qui:
- auth Clerk, workspace logic o feature operative del prodotto;
- componenti shared che dovrebbero vivere in `packages/ui`.

Regole:
- struttura semplice, non forzare FSD;
- link verso login e signup del workspace con URL assoluti del dominio workspace;
- mantieni separazione netta tra marketing e prodotto.

Ordine file: segui `docs/CodePatterns.md`.
