# Web Public

Scopo: asset statici usati solo dal sito marketing.

Metti qui:
- immagini, icone o file pubblici esclusivi di `apps/web`.

Non mettere qui:
- asset brand condivisi con altre app;
- asset temporanei o duplicati.

Regole:
- se un asset serve anche ad altre app, spostalo in `packages/brand`;
- usa naming chiaro e stabile.
