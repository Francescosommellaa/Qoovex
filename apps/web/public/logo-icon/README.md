# Marketing Logo Icon

Scopo: variante locale degli asset logo usati dalla sola app marketing.

Metti qui:
- icone/logo necessari solo alla documentazione marketing.

Non mettere qui:
- asset brand condivisi con sirio o workspace;
- copie quasi identiche con naming ambiguo.

Regole:
- se un logo diventa shared, spostalo in `packages/brand/logo-Icon`;
- conserva solo asset finali e realmente usati.
