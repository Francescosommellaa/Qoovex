# Cursor Rules

Scopo: regole operative applicate automaticamente da Cursor.

Metti qui:
- file `.mdc` con regole attive e stabili del repository.

Non mettere qui:
- bozze scollegate dal repo reale;
- regole obsolete o in conflitto con `project_brain.json`.

Regole:
- una regola qui dentro deve essere sempre allineata con docs e struttura reale del monorepo;
- se un riferimento non esiste piu` nel repo, va rimosso subito.
