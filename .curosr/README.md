# Cursor

Scopo: regole e configurazioni operative dedicate a Cursor.

Metti qui:
- regole che Cursor deve applicare in modo persistente;
- file di supporto direttamente legati al comportamento dell'editor/agent.

Non mettere qui:
- documentazione generica del repo;
- regole duplicate che devono vivere solo nei docs senza impatto su Cursor.

Regole:
- se cambia una regola che Cursor deve rispettare sempre, aggiorna anche `.cursor/rules/qoovex.mdc`;
- le regole qui devono restare coerenti con docs e brain.
