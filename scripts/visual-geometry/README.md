# Visual geometry tooling

These scripts own the local and CI orchestration for the required
`visual-geometry` check. They are intentionally DB-free and operate only on
versioned manifests, repository diffs, built application servers, Playwright,
and reviewed platform-specific PNG baselines.

## Safety boundaries

- Baseline updates are forbidden whenever `CI` is set.
- Local updates require the exact
  `I_ACKNOWLEDGE_INTENTIONAL_VISUAL_CHANGE` attestation.
- Playwright update flags are accepted only when generated by the governed
  runner; arbitrary pass-through update flags fail.
- Shared and unknown frontend changes expand the browser scope conservatively.
- Static drift findings inspect added diff lines only and accept only exact,
  reasoned exemption records.
- Font loading and font identity are deliberately not evaluated.

Use the root `visual:geometry*` scripts once the runner is installed. Do not
invoke internal modules as a substitute for the governed entry points.
