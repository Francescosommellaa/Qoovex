# Packages

Questa cartella contiene il codice condiviso del monorepo.

Metti qui:
- design system, db, tipi, utilita`, config e brand assets condivisi;
- codice riusabile da piu` app o che deve avere una fonte canonica unica.

Non mettere qui:
- routing o runtime specifico di una singola app;
- logica marketing o prodotto strettamente locale a un'app.

Regole:
- ogni package ha un confine chiaro e il suo `README.md`;
- niente duplicazione dello stesso concetto in piu` package.
