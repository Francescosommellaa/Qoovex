# UI Styles

Scopo: fonte canonica dei token e degli stili base condivisi.

Metti qui:
- `tokens.css` e `base.css`, piu` eventuali file CSS shared approvati.

Non mettere qui:
- CSS specifico di una sola app;
- token duplicati o hardcoded fuori standard.

Regole:
- `tokens.css` contiene i token;
- `base.css` contiene il base layer condiviso;
- le app importano questi file, non li duplicano.
