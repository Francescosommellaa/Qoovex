# Font sources

The WOFF2 files in this directory are self-hosted copies served by the official
[Fontshare API](https://www.fontshare.com/):

- Cabinet Grotesk 500 and 700;
- General Sans 400, 500, 600 and 700.

Source CSS: `https://api.fontshare.com/v2/css`.

Only WOFF2 assets are shipped. Runtime UI rendering does not depend on the
Fontshare CDN.
