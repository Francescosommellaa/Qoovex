# UI Components

Scopo: componenti condivisi del design system.

Metti qui:
- button, card, input e ogni componente presentazionale condiviso.

Non mettere qui:
- widget di business;
- wrapper locali a una sola app.

Regole:
- un componente per file con nome esplicito;
- i file TSX seguono `docs/CodePatterns.md`;
- usa solo token semantici e icone Phosphor.
