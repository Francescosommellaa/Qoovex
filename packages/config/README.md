# Config Package

Scopo: configurazioni condivise del monorepo.

Metti qui:
- tsconfig condivisi, config lint/build e file canonici di configurazione tecnica.

Non mettere qui:
- costanti runtime di prodotto;
- utilita` eseguibili o codice business.

Regole:
- ogni sottocartella identifica una famiglia di config;
- cambia qui solo cio` che deve essere centralizzato.
