# Utils Package

Scopo: utilita` pure e hook condivisibili.

Metti qui:
- funzioni pure, parser, formatter e hook che possono essere riusati da piu` app o package.

Non mettere qui:
- business logic fortemente legata a una singola feature del workspace;
- componenti React.

Regole:
- prima di aggiungere un file qui, verifica che il riuso sia reale;
- niente dipendenze da layer FSD delle app.
