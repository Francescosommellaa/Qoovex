Scopo: sorgente TypeScript del package utilities.

Metti qui:
- entrypoint, funzioni pure e sottocartelle di supporto del package.

Non mettere qui:
- config di package;
- codice accoppiato a una sola app.

Regole:
- `index.ts` come API pubblica;
- file piccoli, focalizzati e dal nome esplicito.
